Create a **modern, professional, web-based admin dashboard UI** for my app **Wello**, a local business promotions and cashback rewards platform.

### App context

Wello connects users with local businesses and lets them redeem offers, upload receipts or use bank-linked verification, earn cashback, and cash out rewards. Businesses use Wello to create promotions and track performance.

### Goal

Design a **full admin panel** for the Wello internal team to manage:

* users
* businesses
* offers
* cashback payouts
* receipts and redemption verification
* analytics
* disputes/fraud review
* notifications
* support tickets
* system settings

### Design style

* Clean, modern, startup-quality SaaS dashboard
* Premium and trustworthy look
* Minimal but polished
* Easy to scan, highly organized
* Desktop-first layout
* Rounded cards, subtle shadows, clean spacing
* Use a **white / light neutral background**
* Use **Wello brand colors**: gold/yellow accents, dark text, soft grays
* Professional, not playful or cartoonish
* Strong UX hierarchy with clear sections
* Looks like a real production dashboard, not a concept toy

### Layout

Create:

* **Left sidebar navigation**
* **Top header bar** with search, notifications, admin profile, and quick actions
* Main content area with cards, charts, tables, filters, and modals
* Responsive desktop web app style
